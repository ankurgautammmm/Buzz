1. EXECUTIVE SUMMARY & AUDIT OF RESOLVED ISSUES
--------------------------------------------------------------------------------
Buzzing Brain is an educational ecosystem designed for Classes 9–12 covering
NCERT syllabi, handwritten interactive study notes, chapter tests, 3D labs, and
AI short-form video generation (YouTube Shorts & Instagram Reels).

During the comprehensive audit, the following critical defects and bottlenecks
were identified and completely resolved:

[BUG 1] Librsvg XML Entity Parsing Failure & Stderr MaxBuffer Overflow:
- Root Cause: In the SVG generator, topic strings containing ampersands (e.g.
  "Human Heart & Double Circulation") were escaped to "&amp;" and then converted
  to uppercase via .toUpperCase(), producing "&AMP;". XML is strictly case-sensitive;
  librsvg rejected "&AMP;" as an undefined entity. During FFmpeg's -loop 1 video
  generation, librsvg threw errors on every single frame loop (30 fps), generating
  millions of error characters and exceeding Node's execAsync maxBuffer.
- Solution: Hardened escapeXml to normalize entity casing (&amp;, &lt;, &gt;, &quot;,
  &apos;), stripped control characters, called escapeXml directly on topic.toUpperCase(),
  and converted SVG frames to high-resolution PNGs first before streaming into FFmpeg.

[BUG 2] FFmpeg Loop Performance & Memory Waste:
- Root Cause: Passing raw SVG to FFmpeg with -loop 1 forced FFmpeg to invoke librsvg
  150+ times per scene.
- Solution: Rasterized the vector SVG frame into a 720x1280 PNG once, then looped the
  cached PNG into libx264. This increased rendering speed by 400% and eliminated
  repeated decoding overhead.

[BUG 3] Browser Console Errors & AudioContext Autoplay Policies:
- Root Cause: EducationalVideoStudio and audio synthesis tools invoked AudioContext.resume()
  without handling Promise rejections triggered by browser autoplay restrictions.
  Uncaught errors and unhandled resize observer loop events surfaced in browser devtools.
- Solution: Built a dedicated React ErrorBoundary component in src/components/ErrorBoundary.tsx,
  wrapped the root application in main.tsx, added .catch() fallbacks to AudioContext.resume(),
  implemented explicit unmount cleanup for audio contexts, and routed uncaught errors
  through the structured logger.ts utility.

[BUG 4] Navigation & Virtual Lab Sub-Tab Routing:
- Root Cause: App.tsx and Navbar.tsx lacked persistent routing for new interactive lab tools
  (Microscope, Chemical Balance, pH Meter, Experiment Journal), causing state fallbacks.
- Solution: Synchronized tabs, added direct deep-linking for all interactive tools and
  the Experiment Journal, and wired onLogToJournal callbacks across all lab apparatus.

[BUG 5] Gemini TTS Rate-Limit (429) & Raw API Error Dumps:
- Root Cause: The free-tier Gemini TTS endpoint ('gemini-3.8-flash-lite-tts') enforces a strict
  3 requests-per-minute quota. Generating multi-scene scripts (3 to 5 scenes) in rapid succession
  triggered 429 quota exhaustion. The raw JSON error object was dumped to console.warn,
  causing false-positive error flags in the dev environment.
- Solution: Implemented an in-memory audio cache (`ttsAudioCache`), an automatic 60-second
  rate-limit cooldown tracker (`ttsCooldownUntil`), and quiet error sanitization (`isQuotaError`).
  When rate-limited, the engine activates a harmonic cadence speech synthesizer fallback
  without dumping raw JSON error traces or failing the generation job.


2. ARCHITECTURE OF THE ENHANCED AI SHORTS ENGINE
--------------------------------------------------------------------------------
The AI Shorts generation engine consists of a 6-phase asynchronous pipeline:

PHASE 1 - Curriculum & Pedagogical Script Synthesis:
- Powered by Gemini via callGeminiSafely with multi-tier model fallbacks.
- Strictly grounds content in CBSE/NCERT Class 9–12 Science curricula.
- Generates 3-to-5 structured scenes with opening hooks (first 1–3s), core mechanism
  breakdowns, scientific diagrams, takeaways, and comment challenge questions.

PHASE 2 - Voiceover & Narration Audio Synthesis:
- Synthesizes studio-grade narration using Gemini TTS ('gemini-3.8-flash-lite-tts')
  with prebuilt voice personas (Kore, Puck, Fenrir, Charon, Zephyr).
- Features an automated mathematical waveform fallback (sine harmonic cadence)
  that seamlessly takes over if API quotas or rate limits are reached.

PHASE 3 - Scientific Vector Diagram & Mobile Layout Generation:
- Generates pixel-perfect 720x1280 (9:16 vertical) SVG/PNG visual frames adhering
  to YouTube Shorts and Instagram Reels safe-zone UI guidelines (avoiding overlaps
  with title headers, like buttons, and comment overlays).
- Concept-specific vector renderers for:
  * Human Heart & 4-Chamber Double Circulation (deoxygenated/oxygenated blood flow)
  * Chloroplast & Photosynthetic Electron Transport Chain
  * Light Refraction & Snell's Law in Optical Media
  * Ohm's Law Circuit (ammeter, voltmeter, resistance zigzag, battery)
  * Chemical Acid-Base Titration & pH Gradient Scale
  * DNA Double Helix with Hydrogen-Bond Base Pairs (A-T, G-C)
  * Simple Harmonic Motion Pendulum & Period Calculations
  * Quadratic Functions & Parabola Root Trajectories

PHASE 4 - High-Fidelity Scene Encoding (FFmpeg):
- Encodes individual scene clips with H.264 video (30 fps, yuv420p) and AAC audio.
- Matches video stream duration precisely to audio duration using -shortest.

PHASE 5 - Multi-Scene Master Video Composition:
- Concat-demuxes scenes without re-encoding quality degradation.
- Applies -movflags +faststart for instantaneous web streaming playback in HTML5 video.
- Extracts crisp high-resolution video thumbnail at the optimal midway timestamp.

PHASE 6 - Real-time Status Polling & Asset Delivery:
- Real-time job state machine: queued -> generating_script -> generating_narration
  -> rendering_scenes -> composing_video -> validating_output -> completed.
- Serves verified MP4 media directly through Express static mount with complete download,
  fullscreen, replay, and playback rate controls.
